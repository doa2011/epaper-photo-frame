# nRF52840 首选主控：首批屏幕编译验证

用户已确认 nRF52840 为便携平台首选。先采用官方 DK (PCA10056)；此目录是独立屏幕诊断，不是 BLE/NFC 成品固件。正式通信栈继续评估 Nordic NCS/Zephyr；不能把 Arduino 屏幕编译当作 Nordic NFC SDK 已集成。

## 当前矩阵（结果以 Actions 为准）
| EPD_PANEL | 型号 | IC | 可见分辨率 | 颜色 |
|---|---|---|---|---|
| 1 | GDEM0397F81 | SSD2677 | 800×480 | 四色 |
| 2 | GDEY116F51 | SSD2677 | 960×640 | 四色 |
| 3 | GDEM0213B74 | SSD1680 | 122×250 | 黑白 |

GxEPD2 1.6.7 的型号专用类，使用 8 行分页缓冲。保留各自初始化，不将 3.97 寸 TRES gate 680 参数套用到其他屏。JD79665、UC8151 等须取得准确型号、驱动及电气证据才加入。无任何实机结果。

## 构建

Arduino CLI 1.2.2：

```sh
python -m pip install adafruit-nrfutil==0.5.3.post16
arduino-cli config init
arduino-cli config add board_manager.additional_urls https://adafruit.github.io/arduino-board-index/package_adafruit_index.json
arduino-cli core update-index
arduino-cli core install adafruit:nrf52@1.7.0
arduino-cli lib install --no-deps "Adafruit BusIO@1.16.2" "Adafruit GFX Library@1.11.11" "GxEPD2@1.6.7"
arduino-cli compile --fqbn adafruit:nrf52:pca10056 --build-path build --build-property "compiler.cpp.extra_flags=-DEPD_PANEL=1" firmware/nrf52840/panel_diag
```

修改 EPD_PANEL 为 2/3 可编译另外两款。未知型号拒绝编译。当前 CI 自动矩阵并上传编译日志、清单和生成文件哈希，不发布固件二进制：GxEPD2 GPL-3.0、Adafruit BSP 和 Nordic SoftDevice 许可及 DK bootloader/SoftDevice 布局需核对后再发布可刷包。诊断源文件采用 GPL-3.0-or-later。不要直接将应用 HEX/BIN 当作全量固件写入或擦除 DK。正式刷写及恢复指南待核实。

## 实机前置

仅 DK PCA10056 Arduino BSP 1.7.0 的引脚配置：CS=SS/P1.12，MOSI=P1.13，SCK=P1.15，DC=A0/P0.03，RST=A1/P0.04，BUSY=A2/P0.28。保留 NFC P0.09/P0.10。不要直接套到其他板。裸屏须核对 FPC 针脚、升压外围、3.3V 电源及逻辑、电流和 BUSY。上电不会主动刷新；确认连线后才通过 USB 串口发送 R，观察四色条及 BUSY 日志。返回不等于物理刷新成功。
